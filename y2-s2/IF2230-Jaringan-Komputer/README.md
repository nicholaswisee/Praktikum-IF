# IF2230 Jaringan Komputer

## Deskripsi

Modul ini memuat materi pendahuluan dan praktikum jaringan komputer. README ini berfungsi sebagai indeks belajar, sedangkan penjelasan, contoh, dan langkah praktikum tetap mengacu pada PDF masing-masing pertemuan.

| Praktikum | Kelompok topik | Materi utama |

## Kelompok Topik

### Kelompok 1: Dasar jaringan dan segmentasi

Mulai dengan [PDF Prak 1](prak1/IF2230_PraPrak1_13524037.pdf) untuk mengenal Cisco Packet Tracer (CPT), memahami frame switching pada jaringan LAN, membuat VLAN, dan membagi jaringan menggunakan subnetting.

### Kelompok 2: Konfigurasi alamat dan konektivitas

Lanjutkan ke [PDF Prak 2](prak2/IF2230_PraPrak2_13524037.pdf) untuk mempelajari DHCP, routing antarjaringan, serta konfigurasi wireless router.

### Kelompok 3: Translasi alamat dan akses layanan

Gunakan [PDF Prak 3](prak3/IF2230_PraPrak3_13524037.pdf) untuk mempelajari Static NAT, Dynamic NAT, dan port forwarding sebagai cara mengatur translasi serta akses alamat jaringan.

### Kelompok 4: Layanan jaringan, kontrol akses, dan IPv6

Pelajari [PDF Prak 4](prak4/IF2230_PraPrak4_13524037.pdf) untuk DNS, SSH, Access Control List (ACL), dan IPv6. Gunakan juga [cheatsheet Prak 4](prak4/cheatsheet.pdf) sebagai ringkasan pendamping saat mengerjakan praktikum.

## Progres Belajar

1. Pahami perangkat dan alur komunikasi dasar melalui Kelompok 1.
2. Bangun konektivitas jaringan dengan alamat otomatis, routing, dan wireless router pada Kelompok 2.
3. Pelajari cara jaringan menerjemahkan alamat dan meneruskan akses layanan pada Kelompok 3.
4. Tutup dengan layanan jaringan, pembatasan akses, dan pengalamatan IPv6 pada Kelompok 4.
