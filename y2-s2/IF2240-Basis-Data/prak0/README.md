# Praktikum 0

## Eksplorasi SQL dan Operasi Dasar SQL (SQL Basic Operation)

Praktikum ini berisi eksplorasi basis data dan operasi SQL dasar menggunakan dump yang tersedia di [prak0.sql](prak0.sql).

Materi dapat digunakan untuk berlatih membaca struktur tabel, mengambil data, menyaring baris, memilih kolom, serta memahami operasi dasar SQL sebelum memakai basis data pada praktikum berikutnya.

## Aset

- [Soal Praktikum 0](Soal%20Praktikum%200%20IF2240.pdf)
- [SQL Praktikum 0](prak0.sql)

## Menjalankan praktikum

Tidak ada file `docker-compose.yml` di folder Praktikum 0. Praktikum ini tidak dikelola dengan Docker Compose. Gunakan [Petunjuk Penggunaan MariaDB](../Petunjuk%20Penggunaan%20MariaDB.pdf) untuk menyiapkan MariaDB secara manual, lalu jalankan isi `prak0.sql` pada database yang sesuai.
